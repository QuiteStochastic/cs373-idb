# cs373-idb - House Downing

## Problem & Use Cases
The purpose of this website is to create and display a structured representation of information about the complex Game of Thrones universe to users. This television series is known for its rich and myriad lore. There are many characters, a wide range of locations, a diverse array of influential organizations, and a number of important events that occur throughout the show. It is no surprise that watchers often have difficulty keeping track of everything. This website is meant to aid users in keeping track of this information by allowing them to search for pertinent data on characters, organizations, events, and locations.
